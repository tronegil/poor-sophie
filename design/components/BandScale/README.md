# BandScale

Skalaen fra 0 til 10 med alle fem bånd, slik forsiden forklarer «Hva tallene betyr».

- En flat liste med `line`-skillelinjer, ikke et kort med skygge.
- Hver rad: intervall-chip i båndfargen (mono), båndnavn i halvfet, båndets setning i `ink-muted`.
- På smal skjerm faller setningen under navnet.

Forbrukeren gir: de fem båndene med intervall, navn og setning (fra `landing.bands`).
