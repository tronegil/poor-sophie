# NavBar

Navigasjonslinja på `deep`: ordmerket til venstre, lenker og språkvelger til høyre.

- Ordmerket er navnet satt i `display`-fonten, fulgt av en liten `magenta`-prikk (et fyr i kartet). Ingen emoji.
- Aktiv side markeres med 2px `magenta`-strek under, ikke med farget tekst.
- Språkvelgeren er en pille med NO / EN; valgt språk er en lys pille (`on-deep`) med `deep` tekst.
- På forsiden (Kvalmeindeks) står «Kvalmeindeks» som ordmerke og innlogging ligger i bunnteksten.
- 56px høy. Holder seg på `deep` i begge temaer.
